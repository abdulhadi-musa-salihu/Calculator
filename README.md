# Calculator

Basic scientific calculator (HTML + JavaScript). Used to teach Git & GitHub.

Live pages:
- `index.html` — the calculator
- `contributors.html` — class contributors list (assignment)

## Student assignment: add your name

1. Clone: `git clone https://github.com/garba-the-analyst/Calculator.git`
2. Branch: `git checkout -b add/your-full-name`
3. Edit `contributors.html` — copy the `<li>` template, add your name (don't touch others)
4. Commit & push:
   `git add contributors.html`
   `git commit -m "Add Your Name to contributors"`
   `git push -u origin add/your-full-name`
5. Open a Pull Request on GitHub for review

## Run locally

Just open `index.html` in a browser. No build step.
